# 휴롬 과일청 메이커 (가칭) — 신제품 기획 제안서 v1 첫판

- 페이지: https://simjb23-oss.github.io/hurom-fruitcheong/
- 한 줄: 과일과 설탕을 넣으면 저어 녹이고 알맞은 온도로 숙성해, 곰팡이 걱정 없이 청을 완성하는 조리대 가전. 유리 통(약 2L) + 바닥 자석 젓개 + 통 바깥(알루미늄 컵) 펠티어 + 뚜껑 한 방향 밸브. 받침은 낮고 얇게, 유리 통이 주인공, 받침 빛이 통을 아래서 비춤.
- 시작: 2026-11-16 #신제품개발팀 (준보 「계절가전 뭐 해보까? 색다른거」 → 두팔 후보 3개 → 준보 「1번가자」 · 「무조건 이뻐야한다」). 담당: 페이지·3D 강명식, 시장·경쟁·온도·시간·안전·가격 곽두팔.
- 디자인 시안 3개: A 항아리형 유리 + 흰 무광 받침(추천) · B 원통 유리 + 연회색 세라믹 받침 · C 넓적한 낮은 통 + 베이지 받침. 나무 안(뚜껑 손잡이·받침 윗테). 색 단추: 유자·매실·오미자·딸기 — 통 안 청 색과 받침 빛이 같이 바뀜.
- 빈칸(두팔이 채움): 온도 · 숙성 시간 · 크기 · 원가 · 판매가 · 개발비. 페이지에는 「추정 예정」. 3D 치수는 가정(시안 A 받침 Ø19 × 5cm · 통 배 Ø16 × 16cm).
- 구조 3D: `explode.js` (three.js, 스크롤: 저녁 앞모습 → 낮 뒷모습 → 속 → 분해도 · 부품 14개). 쿼리: `?p=0~1` 진행도 · `?v=a|b|c` 시안 · `?c=yuja|maesil|omija|strawberry` 청 색 · `?wood` 나무 안 · `?night` / `?day` 장면 고정 · `?ang=<도>` 카메라 · `?cy=` 높이 · `?noadapter ?noairg ?nofruit` 숨기기.
- 최종 이미지: `captures/` = `img/` (hero 저녁 장면 · a/b/c 시안 · wood 나무 안 · c_* 색 4개 · explode 분해도). 캡처: work/ 에서 `python -m http.server 8766` 후 `test/shot.sh` 또는 test/t.html 에 쿼리.
